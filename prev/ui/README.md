# ui

This archived Vue 2 application uses Node's OpenSSL legacy provider in its npm
scripts because its webpack version predates OpenSSL 3.

## Project setup
```
npm install
```

### Compiles and hot-reloads for development
```
npm run serve
```

### Compiles and minifies for production
```
npm run build
```

### Lints and fixes files
```
npm run lint
```
